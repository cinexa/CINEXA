# 스킬 한글 설명

사용자는 개발자가 아니고, 영어 설명을 읽기 어려워합니다.
스킬 목록을 물어보면 **아래 표를 한글 그대로** 보여주세요.

사용자가 특정 스킬 하나만 물으면, 그 줄만 뽑아서 보여주고
**"이럴 때 쓰면 좋아요"** 예시를 한 줄 덧붙이세요.


---

## 📄 문서 · 파일 만들기

| 스킬 | 한글 설명 |
|---|---|
| `/docx` | **워드 문서(.docx) 다루기.** 보고서·메모·편지 만들기, 기존 워드 파일 읽고 고치기, 표·목차·쪽번호 넣기, 변경 이력·메모 확인. "워드로 만들어줘" 하면 이게 켜져요. |
| `/xlsx` | **엑셀 파일(.xlsx, .csv) 다루기.** 표 만들기, 수식 계산, 서식·차트 넣기, 지저분한 데이터 정리, 파일 형식 바꾸기. |
| `/pptx` | **파워포인트(.pptx) 다루기.** 발표 자료 만들기, 기존 장표 읽고 고치기, 템플릿·발표자 노트 작업. |
| `/pdf` | **PDF 다루기.** 글·표 뽑아내기, 여러 개 합치기, 자르기, 회전, 워터마크, 새 PDF 만들기, 양식 채우기, 암호 걸기·풀기, 스캔본 글자 인식(OCR). |

## 🎨 보여주기 · 디자인

| 스킬 | 한글 설명 |
|---|---|
| `/design` | **디자인 캔버스 만들기.** 여러 화면을 한 판에 펼쳐놓고 눈으로 보며 고칠 수 있는 시안. 앱 화면, 랜딩페이지, 포스터, 전단지, 카드뉴스 등. |
| `/dataviz` | **차트·그래프 잘 그리기 규칙.** 막대·선·원 그래프, 대시보드를 보기 좋고 색맹도 구분되게 만드는 기준. 그래프 만들 때 자동으로 적용돼요. |
| `/artifact-design` | **아티팩트(웹페이지 결과물) 디자인 기준.** 웹으로 보여주는 결과물을 예쁘고 읽기 좋게 만드는 규칙. |
| `/artifact-diagramming` | **아티팩트 안에 도표·흐름도 그리기.** 그림으로 설명하는 게 나을 때 쓰는 방법. |
| `/artifact-capabilities` | **아티팩트에 기능 넣기.** 만든 웹페이지가 투표를 저장하거나, 체크리스트를 기억하거나, 파일을 받도록 만들 때. |

## 🧑‍💻 코드 · 개발 (개발자용)

| 스킬 | 한글 설명 |
|---|---|
| `/code-review` | **바뀐 코드 검사.** 버그와 지저분한 부분을 찾아서 알려줍니다. `--fix` 를 붙이면 바로 고쳐줘요. |
| `/simplify` | **코드 정리.** 버그 찾기는 안 하고, 중복되거나 복잡한 부분만 깔끔하게 다듬어 고칩니다. |
| `/security-review` | **보안 점검.** 지금 작업한 내용에 보안 위험이 있는지 확인합니다. |
| `/init` | **프로젝트 설명서 만들기.** 이 프로젝트가 어떤 구조인지 정리한 `CLAUDE.md` 를 새로 만듭니다. |
| `/run` | **만든 걸 직접 실행해서 확인.** 앱을 켜보고 화면을 찍어서 잘 되는지 눈으로 보여줍니다. |
| `/claude-api` | **Claude API 사용법 참고서.** 모델 이름, 가격, 옵션 등. 프로그램에 Claude를 붙일 때 씁니다. |
| `/mcp-builder` | **MCP 서버 만들기.** Claude가 외부 서비스(예: 회사 시스템)를 쓸 수 있게 연결 도구를 만드는 작업. |

## ⚙️ Claude 설정 바꾸기

| 스킬 | 한글 설명 |
|---|---|
| `/update-config` | **Claude 동작 설정 바꾸기.** "앞으로 ~할 때마다 자동으로 ~해줘" 같은 자동 동작, 권한 허용, 환경 설정. |
| `/keybindings-help` | **단축키 바꾸기.** 키보드 단축키를 내 마음대로 설정. |
| `/fewer-permission-prompts` | **"허용할까요?" 창 줄이기.** 자주 쓰는 안전한 명령을 미리 허용 목록에 넣어줍니다. |
| `/loop` | **반복 실행.** "5분마다 ~확인해줘" 처럼 정해진 간격으로 계속 실행. |
| `/session-start-hook` | **세션 시작 준비 설정.** 대화창을 열 때마다 자동으로 준비 작업(설치 등)을 하도록 설정. |
| `/skill-creator` | **새 스킬 만들기.** 나만의 `/명령어` 를 새로 만들거나 기존 걸 고칩니다. |
| `/import-memory` | **다른 AI의 기억 가져오기.** 다른 AI 서비스에서 내보낸 기억을 Claude로 옮깁니다. |
